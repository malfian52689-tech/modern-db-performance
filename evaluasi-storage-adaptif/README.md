# Evaluasi Sistem Penyimpanan Data Adaptif dalam Analisis Data Kompleks

Dokumen utama tugas tersedia pada [laporan.md](laporan.md). Tugas ini disusun berdasarkan asesmen Pertemuan 11 dan Sub-CPMK-2.5 level C4, yaitu mengevaluasi kelebihan dan kekurangan sistem penyimpanan data adaptif.

Isi tugas mencakup halaman sampul, pendahuluan, landasan teori, metode, hasil dan pembahasan, kesimpulan dan saran, daftar pustaka, serta lampiran.
